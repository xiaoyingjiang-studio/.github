# 小影匠工作室

**把想法做成视频，把细节改到满意。**

我们关注 AI 辅助视频创作，把中文学习资料、可查看的作品和可继续修改的项目整理到一起。目前围绕 HyperFrames，维护中文指南与案例资源精选。

[访问中文网站](https://xiaoyingjiang.com/) · [从 Studio 开始](https://xiaoyingjiang.com/start/studio/) · [浏览案例与资源](https://github.com/xiaoyingjiang-studio/awesome-hyperframes) · [推荐一份资源](https://github.com/xiaoyingjiang-studio/awesome-hyperframes/issues/new/choose)

## 找到你的下一步

- **第一次接触 HyperFrames**：先读 [Studio 中文上手](https://xiaoyingjiang.com/start/studio/)，了解创作入口与使用条件。
- **已经有内容，想找做法**：从[原创案例](https://xiaoyingjiang.com/showcase/)挑一个接近的场景，查看成片并下载项目。
- **想研究源码与工作流**：查看[中文指南工程](https://github.com/xiaoyingjiang-studio/hyperframes-cn)和 [HyperFrames 官方项目](https://github.com/heygen-com/hyperframes)。

## 一起把资料做得更好

欢迎[推荐作品或工具](https://github.com/xiaoyingjiang-studio/awesome-hyperframes/issues/new/choose)、[反馈指南问题](https://github.com/xiaoyingjiang-studio/hyperframes-cn/issues/new/choose)，或按[贡献说明](https://xiaoyingjiang.com/community/contributing/)提交改进。

分享时请附上作者、原始链接、使用场景、源码或素材许可，以及你实际验证过的步骤。我们重视清楚的出处、具体的方法和诚实的验证记录。
