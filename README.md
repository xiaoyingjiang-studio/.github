# 小影匠工作室 · 组织主页

本仓库维护 [xiaoyingjiang-studio](https://github.com/xiaoyingjiang-studio) 的 GitHub 公开主页。面向访问者的内容位于 [`profile/README.md`](profile/README.md)，由 GitHub 在组织 Overview 中展示。

## 维护方式

- 修改组织介绍、项目入口与案例展示时，先创建分支和 PR，由维护者检查后手动合并。不要自动合并。
- 介绍以现有项目为依据，不虚构团队规模、用户数、作品效果、官方合作或实际测试。
- 案例图片引用 `hyperframes-cn` 已存在素材的固定提交，不复制第三方素材；案例说明、项目源码和验证记录仍由原仓库维护。
- 组织主页服务于项目发现，不复制整套教程或案例目录。新增资源进入 `awesome-hyperframes`，网站内容进入 `hyperframes-cn`。
- 这里只维护公开主页，不添加组织级默认 Issue / PR 模板或其他会影响现有仓库的文件。

## 审核清单

1. 检查文字、来源、图片、链接和独立社区身份说明。
2. 在 GitHub 的 Markdown 渲染视图检查桌面和窄屏阅读，确认图片替代文字和链接清楚。
3. 手动合并后检查组织公开 Overview；不要把 PR 预览当作已发布。

机制说明：[GitHub 组织主页文档](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile)。

## 归属

主页展示的四个案例由小影匠工作室维护，源文件、字体及其他素材的许可与归属见 [hyperframes-cn 的声明](https://github.com/xiaoyingjiang-studio/hyperframes-cn/blob/2cbf04a35769f80bc6dff8f6332054d63d6cc9e1/THIRD_PARTY_NOTICES.md)。原项目许可不因主页展示而改变。
